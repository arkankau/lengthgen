# Paper Package

This directory contains the detection-first paper scaffold for Null-Attractor Attention.

Read in this order:

1. `outline.md`
2. `claims_and_evidence.md`
3. `key_paper_move.md`
4. `thermodynamic_attractor_derivations.md`
5. `figures_to_generate.md`
6. `limitations.md`
7. `related_work.md`
8. `evidence_report.md` after running `scripts/summarize_paper_evidence.py`

Claim boundary:

> This is a thermodynamic diagnostic framework for jailbreak-like latent states, not a validated generation-time jailbreak defense.

Generation-time null intervention belongs in the negative-control and limitations framing. It is not a core contribution claim.
